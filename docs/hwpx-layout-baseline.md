# Baseline 조판 (관찰 근거) — 그룹 A / 그룹 B

**역할**: 이 문서는 기존 HWPX 문서들이 **실제로 어떻게 조판되어 있었는가**를
기록하는 관찰/증거 계층이다. 앞으로 무엇을 쓸지 결정하는 계층이 아니다 —
그 결정은 `docs/contracts/institution-design-contract.schema.json`이 정의하는
Institution Design Contract의 책임이다.

```text
Baseline           = what was observed
Institution Design Contract = what we choose to use
```

`analysis_by_doctype.md`/`sandbox/template-spec-analysis/analyze_deep.py`
(header.xml 등록값과 section*.xml 실제 참조를 교차 확인한 스크립트)로 확인된
그룹별 관찰을 정리한다. 특정 기관 파일을 그대로 베낀 것이 아니라 그룹 단위로
정리했을 뿐, 관찰값 자체를 편집하거나 골라내지는 않는다.

각 항목은 아래 성격 중 하나로 분류해 기록한다. **한 파일에서만 관찰됐다는
이유로 관찰 기록 자체를 지우지 않는다** — "그룹 공통 규칙으로 확정할 수
없다"는 뜻이지 "관찰하지 않았다"는 뜻이 아니다.

- `COMMON` — 관찰 대상 전체(예: 그룹 A 5/5, 그룹 B 2/2)에서 동일하게 관찰됨.
- `REPEATED` — 그룹 내 다수(과반 이상)에서 반복 관찰되나 전체 공통은 아님.
- `DOCTYPE_SPECIFIC` — 특정 하위 문서유형(예: 원장보고류)에서만 반복됨.
- `SINGLE_OBSERVATION` — 그룹 내 정확히 1개 파일에서만 관찰됨.
- `VARIABLE` — 파일마다 값이 다르고, 공통 규칙이나 다수 패턴이 보이지 않음.
- `UNUSED_EDITOR_DEFAULT` — header.xml에는 등록돼 있으나 section*.xml에서
  실제로 참조되지 않아(styleIDRef/paraPrIDRef/charPrIDRef 실사용 0회) 렌더링에
  영향을 주지 않는 한/글 편집기 자동 값. 검증 방법과 결과는 "baseline 관찰에서
  제외한 것" 절 참고.

이번 라운드 범위: 그룹 A(한장/원페이지 보고서), 그룹 B(보도자료). 업무정보·
위생점검표는 제외 (2026-08-13 확정, 문서유형이 그룹 A/B와 달라 참고 대상에서
뺀 것 — 관찰값 자체를 지운 것이 아니라 애초에 이 라운드의 분석 대상이 아니었다).

**2026-08-13 개정**: 1차 버전은 "무엇이 들어가는가"(구성요소·폰트 종류·표 개수)만
다뤘고 "어떻게 생겼는가"(여백·정렬·들여쓰기 수치·표 폭/테두리/셀 여백·색상·로고·
footer)가 빠져 있다는 지적을 받고 재분석했다. 이번 분석은 두 가지 방법을 같이 썼다.

1. **문서 자체가 명시한 조판 지시문**: 이 샘플들은 실제로 채워진 완성 보고서가
   아니라 "본문 (휴먼명조 15, 장평 100%, 줄간격 150)"처럼 각 요소에 쓸 폰트·크기·
   장평·줄간격을 문서 자체 텍스트로 명시해 둔 **서식 안내/샘플 문서**였다. 이건
   추측이 아니라 기관이 직접 적어놓은 값이므로 가장 신뢰도 높은 근거로 삼았다.
2. **XML 실측**: `hp:pagePr`(페이지 크기/여백), `hh:paraPr`(정렬/줄간격/들여쓰기),
   `hp:tbl`/`hp:tc`(표 폭/테두리/셀여백/배경색), `hh:borderFill`(테두리 두께·색),
   `hp:pageNum`(쪽번호) 등을 직접 파싱했다.
   (스크립트: `sandbox/template-spec-analysis/analyze_layout.py`,
   `dump_fulltext.py`)
3. **한/글 육안 확인 (2026-08-13 추가)**: 위 두 방법으로도 XML만으론 판별
   못 한 두 가지(제목 실제 정렬, 개조식 단계별 정확한 들여쓰기)를 실제 설치된
   한/글(HOffice 2022)로 금감원 원장보고·금감원 보도자료 2개 파일을 직접 열어
   화면으로 확인했다. 결과는 각 그룹 절과 하단 "확인 필요" 목록에 반영했다.
   수정 없이 열람만 했다.

## 그룹 A — 한장/원페이지형 보고서 baseline

근거 파일: 광주 한장보고서, 금감원 원장보고×2, 금감원 원페이지, 한국농어촌공사 한페이지

### 1. 페이지 기본값 (5/5 실측)

| 파일 | 용지 | 좌/우 여백 | 상/하 여백 | header/footer 여백 |
|---|---|---|---|---|
| 광주 한장보고서 | A4 세로 | 20.0mm | 상15.0 / 하10.0mm | 15.0mm |
| 금감원 원장보고 | A4 세로 | 20.0mm | 10.0mm | 10.0mm |
| 금감원 원페이지 | A4 세로 | 20.0mm | 8.0mm | 8.0mm |
| 금감원 원장보고(가상자산) | A4 세로 | 20.0mm | 10.0mm | 10.0mm |
| 한국농어촌공사 한페이지 | A4 세로 | 20.0mm | 15.0mm | 10.0mm |

- **A4 세로가 5/5 전부 공통** (`COMMON`).
- **좌/우 여백 20mm이 5/5 전부 공통** (`COMMON`).
- 상/하 여백은 `VARIABLE`이다 — 상/하가 파일 안에서도 서로 다른 값일 수 있다
  (광주는 상15.0mm/하10.0mm으로 상하가 다름). 상/하를 따로 집계하면:
  - 상 여백: 15.0mm 2/5, 10.0mm 2/5, 8.0mm 1/5 — 최빈값 동률, 그룹 전체
    공통값 없음.
  - 하 여백: 10.0mm 3/5, 8.0mm 1/5, 15.0mm 1/5 — 10.0mm이 5개 중 3개로 가장
    흔하지만 전체 공통(5/5)은 아니다.
  - 관찰 범위: 8~15mm. 어떤 값을 실제로 쓸지는 Institution Design Contract가
    결정할 사항이며, 이 관찰 결과는 baseline이 특정 값을 채택했다는 뜻이 아니다.

### 2. Masthead / 헤더 영역

- **로고: 5/5 전부 이미지 객체(`hp:pic`) 0개** (`COMMON`). 실제 삽입 이미지로서의
  로고를 쓴 샘플은 그룹 A에 하나도 없다는 것이 관찰 결과다. 로고를 넣을지·
  어떤 방식으로 넣을지는 이 관찰만으로 정해지지 않으며 Institution Design
  Contract가 결정할 사항이다.
  (2026-08-13 한/글 육안 확인: 그룹 B의 금감원 보도자료에는 로고처럼 보이는
  그래픽이 masthead에 있었으나, 이 역시 `hp:pic`는 0개였다 — 아래 그룹 B
  2번 참고. 즉 "그룹 A/B 전체에 실제 이미지 객체로 삽입된 로고는 0개"가 맞다.)
- **제목 상자(테두리/배경으로 감싼 제목): 5/5 전부 없음.** 섹션 제목("1. 추진
  배경" 등)은 상자 없이 좌측 정렬 텍스트로만 온다. 단, masthead 자체는 상자
  없는 게 아니라 **표로 짜여 있다** — 아래 참고.
- **제목 정렬 (2026-08-13 한/글 육안 확인으로 해소)**: 금감원 원장보고를
  한/글로 직접 열어 확인한 결과, 섹션 제목("1. 추진 배경(HY헤드라인M 16)")은
  **좌측 정렬**, 페이지 좌측 여백에 바로 붙는다. XML의 문단 정렬(`align`)만으로는
  판별 안 됐던 이유는 표가 문단에 인라인 삽입(`treatAsChar="1"`)돼 있어서였고,
  실제 렌더링에서는 좌측 정렬이 명확했다 → **관찰 확정: 섹션 제목 좌측 정렬**.
- **masthead 구조 (2026-08-13 한/글 육안 확인으로 추가)**: 금감원 원장보고의
  최상단은 "단순 텍스트 한 줄"이 아니라 **1행 2~3열 표**였다 — 좌측 작은 셀에
  `"현안(이슈)보고 (2026. 7. 9.)"`(테두리만, 배경 없음), 우측 큰 셀에 진한
  남색(#2B2D63) 배경의 배너 `"◎◎◎◎ 진행현황"`(흰 굵은 글씨, 셀 안에서 가운데
  정렬). 바로 아래 줄에 체크박스형 상태 표시(`□ 현안검토 □ 언론보도 ...`),
  그 아래 연주황(#FFE7D8) 박스로 `"☑ 요약 또는 배경"` — 이 3단 구성이 원장보고형
  masthead의 실체였다. 앞서 "표 조판" 절에서 관찰한 2행3열 표(배경 #2B2D63)가
  바로 이 배너임이 이번에 확인됐다.
- 날짜/작성부서 병기 줄은 우측 정렬로 관찰된 사례가 있음(금감원 원페이지:
  `align=RIGHT`) — 단일 관찰.

### 3. 제목·본문 폰트/크기 계약 — **문서 자체가 명시한 값 (가장 신뢰도 높음)**

금감원 원장보고류 2개 파일 본문에 아래 지시문이 그대로 적혀 있다(실제 지어낸 값
아님, 원문 인용):

```
1. 추진 배경 (HY헤드라인M 16)
□ 본문 (휴먼명조 15, 장평 100%, 줄간격 150)
◦ 본문 (한칸 들여쓰기)
* 세부통계 등 (맑은 고딕 12, 장평 100%, 줄간격 130)
† 맑은고딕 11pt
※ 1페이지 하단에 보고자 및 연락처 등 표시
```

금감원 원페이지 파일에는:

```
(맑은고딕 15pt) 휴먼명조 15pt   ← 섹션 제목(가/나 레벨)
(휴먼명조 13pt)                 ← 섹션 본문
⇨ 휴먼명조 15pt                 ← 결론/화살표 뒤 텍스트
```

**판정**: 그룹 A 섹션 제목은 16pt급(HY헤드라인M 또는 맑은고딕 15pt대),
□ 단계 본문은 15pt대(휴먼명조 계열), 세부/각주성 텍스트는 11~12pt(맑은 고딕)
로 3단 크기 위계가 있다는 것은 (문서가 직접 명시한 값 기준으로) `DOCTYPE_SPECIFIC`
패턴으로 반복 관찰된다(원장보고류 2개 파일 + 원페이지 1개 파일). "휴먼명조"·
"HY헤드라인M"을 이번 template_spec에서 그대로 쓸지는 baseline이 정하지 않는다
— 아래 실측 결과가 보여주듯 정확한 font family는 파일마다 갈리므로, 어떤 실제
폰트를 쓸지는 Institution Design Contract의 결정 사항이다.

#### 3-1. 실제 사용 폰트 실측 — header 등록값이 아니라 section 실제 참조 기준

`header.xml`의 fontface/charPr 등록 테이블만으로는 "실제 조판에 쓰였는지"를
알 수 없다 — 반드시 `section*.xml`의 `<hp:run charPrIDRef=...>`가 그 charPr을
실제로 참조하는지 교차 확인해야 한다(스크립트:
`sandbox/template-spec-analysis/analyze_deep.py`, 이번 재검증에서 top-10
제한 없이 전체 재실행해 재확인함). 그 결과:

**그룹 A(5개 파일)에서 실제 run이 참조한 font family**(파일당 중복 제거,
정확한 크기/bold는 문서·역할마다 다름 — 아래는 "그 폰트가 그 문서 안에서
쓰이긴 했는가"만 집계):

| font family | 관찰 | 분류 |
|---|---|---|
| 맑은 고딕 | 5/5 전 파일에서 실제 run 사용 확인 | `COMMON` |
| 함초롬바탕 | 5/5 전 파일에서 실제 run 사용 확인 | `COMMON` |
| HY헤드라인M | 5/5 전 파일에서 실제 run 사용 확인 | `COMMON` |
| 명조 | 5/5 전 파일에서 실제 run 사용 확인 | `COMMON` |
| 휴먼명조 | 3/5(광주, 원페이지, 한국농어촌공사) | `REPEATED` |
| HY견명조 | 1/5(금감원 원페이지) | `SINGLE_OBSERVATION` |
| 함초롬돋움 | 1/5(광주) | `SINGLE_OBSERVATION` |

**그룹 B(2개 파일)**:

| font family | 관찰 | 분류 |
|---|---|---|
| 맑은 고딕 | 2/2 | `COMMON` |
| 함초롬바탕 | 2/2 | `COMMON` |
| 명조, HY헤드라인M, 굴림 | 금감원 보도자료 1/2 | `SINGLE_OBSERVATION` |
| 돋움체, 바탕, 함초롬돋움 | 한국농어촌공사 언론보도 1/2 | `SINGLE_OBSERVATION` |

주의: 같은 font family가 여러 파일에 걸쳐 실제로 쓰였다는 것이 **같은 역할
(제목/본문/각주)에 일관되게 쓰였다는 뜻은 아니다** — 위 실측은 "그 폰트가 그
문서 안에서 실제로 쓰였는가"만 확인한다. 크기(300~2000/100pt)와 bold 여부가
문서마다 크게 갈려, family 단위 공통성만으로 "제목=이 폰트"라는 역할 매핑을
끌어내지 않는다. `HCI Poppy`, `한양신명조`, `한양중고딕`은 여러 파일의
`header.xml`에 등록되어 있었지만, 그룹 A/B 어느 파일의 `section*.xml` run에서도
단 한 번도 참조되지 않음을 확인했다(0회) — 즉 이 세 개는 실사용이 아니라
`UNUSED_EDITOR_DEFAULT`다. 반대로 `돋움체`(한국농어촌공사 언론보도에서 15회로
그 문서의 최다 사용 폰트)·`바탕`·`HY견명조`·`굴림`은 반복 빈도는 낮아도(그룹
내 1/5 또는 1/2) 실제로 쓰인 값이므로 관찰 기록에서 제외하지 않는다.

**결론**: 제목/본문/각주에 굵고 큰 헤드라인체·명조/고딕 계열이 반복 등장하는
경향은 관찰되지만, **어떤 문서에도 예외 없이 적용되는 단일 exact font family
규칙은 없다.** 폰트가 맡는 역할의 경향(제목=굵고 큰 헤드라인체, 본문=명조/고딕
중 하나, 각주=고딕 소형)은 반복 관찰된 패턴이라는 사실만 기록한다 — 이 패턴을
실제 template_spec에 채택할지, 그렇다면 정확히 어떤 폰트로 채택할지는 baseline이
아니라 Institution Design Contract가 결정한다.

### 4. 개조식 위계 — 실측 + 원문 지시문 종합

- **불릿 문자 자체는 5/5 전부 `□ → ㅇ/◦ → -` 3단 공통** (`COMMON`, 이전
  분석과 동일).
- 한국농어촌공사 한페이지는 4단(`□ → ㅇ → - → *`)까지 쓰는 사례가 있음 —
  `SINGLE_OBSERVATION`, 4단계까지 쓰는 사례가 실제 존재한다는 사실은 기록에
  남긴다.
- 광주 한장보고서는 3단 공통 기호 세트와 별개로 `󰏅`, `❍` 기호도 실제로
  쓴다 — `SINGLE_OBSERVATION`(5개 중 1개). 반복 빈도가 낮다고 해서 이 관찰
  자체를 지우지 않는다: 그룹 전체 공통 불릿 문자로 확정할 수 없다는 뜻일
  뿐, 광주 한장보고서에 이 기호가 실제로 쓰였다는 사실 자체는 유효한 관찰이다.
- **들여쓰기 수치 (2026-08-13 한/글 육안 확인으로 해소)**: XML의 `hh:margin`
  값(`left`/`intent`)만으로는 계단식 들여쓰기 여부를 확정할 수 없었는데(같은
  값에 대해 `hp:case`/`hp:default` 두 표기가 동시에 존재해 어느 쪽이 실제
  렌더링에 쓰이는지 판별 불가), 금감원 원장보고를 한/글로 직접 열어 눈금자로
  확인한 결과 **실제로 단계마다 계단식으로 들여쓰기 된다**:
  - □ 단계: 페이지 좌측 여백 기준 0 (들여쓰기 없음)
  - ㅇ/◦ 단계: □보다 약 +0.5cm
  - * 단계(세부통계 등): ㅇ보다 약 +0.5cm 더 (좌측 여백 기준 총 +1cm)
  - † 단계(각주 기호): *보다 약 +0.3cm 더
  → **관찰 확정**(금감원 원장보고 1개 파일 육안 확인, `SINGLE_OBSERVATION`을
  원문 지시문 `"◦ 본문 (한칸 들여쓰기)"`가 다른 파일에서도 뒷받침): 불릿
  단계당 약 0.5cm(±) 계단식 들여쓰기가 관찰된다. 정확한 mm는 파일마다 조금씩
  다를 수 있어 "약 0.5cm 단위"라는 관찰 수준으로만 기록하고, 실제 template_spec
  값으로 쓸지·정확히 몇 mm로 쓸지는 Institution Design Contract가 결정하며
  hwpx 렌더링으로 재검증이 필요하다.

### 5. 표 조판 — 실측

- **표 폭**: 대부분 168~173mm — 좌우 여백 20mm(본문 폭 170mm)와 거의 일치.
  즉 **표가 본문 폭 전체(100%)를 채우는 배치가 그룹 A 대부분에서 관찰된다**
  (`REPEATED`). 예외적으로 금감원 원페이지의 3열 요약 표는 68.3mm(본문 폭의
  약 40%)로 좌우 2단 배치용 좁은 표를 쓴 사례가 있음 — `SINGLE_OBSERVATION`
  으로 기록.
- **테두리 굵기**: `0.12mm`(가는 실선, 셀 안쪽 구분선)와 `0.4mm`(굵은 실선,
  표 외곽·강조선)의 2단계가 그룹 내 반복 관찰됨(5개 중 4개, `REPEATED`).
  `DASH`(점선)도 구분/참고 정보 표시에 보조적으로 등장.
- **셀 안쪽 여백(`cellMargin`)**: 좌우 1.8mm / 상하 0.5mm가 가장 흔히 관찰된
  값(5개 중 3개, `REPEATED`), 배경색이 꽉 찬 배너형 표는 0/0/0/0(여백 없음)을
  쓰는 경우가 있음(제목 배너, 강조 바 형태 표).
- **셀 배경색(음영)**: 표마다 다른 강조색을 쓰지만(아래 6번), 색이 없는(흰
  배경) 표도 다수 섞여 있다 — 관찰된 사실은 "모든 표에 음영이 있지는 않고,
  일부 표에만 음영이 있다"이다. 어느 표에 음영을 넣을지는 이 관찰만으로
  정해지지 않는다.
- **표 배치 패턴**: "시간/내용/비고" 3열 진행순서 표가 광주·한국농어촌공사
  2개 파일에서 동일한 열 구성으로 반복됨 — `SINGLE_OBSERVATION`에 가까운
  약한 반복(2/5)으로 기록. 일정표 섹션의 표준 열 구성 후보로 참고할 수는
  있으나, 신뢰도가 높다고 주장하지 않는다.

### 6. 색상 — 실측

실제 cell 배경(`fillBrush`)·테두리(`borderFill`) 색을 XML에서 직접 읽은 값이다
(스크립트: `sandbox/template-spec-analysis/analyze_layout.py`의
`colors_used` 수집 로직). 각 파일이 서로 다른 강조색을 쓴다 — 이 값 자체는
실제 관찰이므로 baseline 기록에서 지우지 않는다. 이 색을 그대로 쓸지, 다른
색으로 바꿀지는 이 문서가 정하지 않는다 — Institution Design Contract의 결정
사항이다.

| 파일 | 사용 색상 |
|---|---|
| 광주 한장보고서 | `#0080C0`(파랑 배너), `#EAEAEA`(연회색 표) |
| 금감원 원장보고 | `#1B1760`,`#2B2D63`(남색 배너), `#FFE7D8`,`#FFF7CC`(연주황/연노랑 강조) |
| 금감원 원페이지 | `#0000FF`, `#3E57A5`, `#CDF2E4`, `#E0E5FA`, `#FAFABF`(다색 강조 박스) |
| 한국농어촌공사 한페이지 | `#0080C0`(파랑 배너), `#F2F2F2`(연회색 표) |

**판정**:

- **exact color value**: 문서/기관별로 다르다. `#0080C0` 파랑 배너가
  광주·한국농어촌공사 2곳에서 겹치는 것(2/5, `REPEATED`) 외에는 겹치는 값이
  없다 — 그룹 전체 공통 exact color는 없다.
- **usage pattern**: "제목/구분 배너에는 진한 단색, 본문 표에는 연한
  회색조/파스텔"이라는 사용 패턴은 4개 파일에서 반복 관찰된다(`REPEATED`) —
  이 패턴 자체를 관찰로 기록하는 것과, 이 패턴을 실제로 채택해 특정 색을
  정하는 것은 다른 결정이다. 후자는 Institution Design Contract가 한다.
- 실제 색값을 그대로 재사용할지는 `확인 필요` — baseline은 "재사용해도
  된다/안 된다"를 판단하지 않는다. 각 색이 특정 기관 고유 브랜드 컬러인지,
  단순히 작성자가 그때그때 고른 강조색인지도 baseline은 추측하지 않는다
  (원인 추론 없음).

### 7. 이미지 — 실측 + 원문 지시문

- 그룹 A 5개 전부 `hp:pic` 이미지 객체 0개(`COMMON`). 그룹 B(한국농어촌공사
  언론보도)에서 "그림1", "그림2"라는 **텍스트 라벨 placeholder**를 쓰는 걸
  확인했다(실제 이미지 객체 아님, 순수 텍스트, `SINGLE_OBSERVATION` — 그룹 B
  2개 중 1개). 그룹 A에는 이런 그림 placeholder조차 관찰되지 않았다
  (`COMMON`, 5/5 없음). 이미지 삽입 자리를 그룹 A에 둘지는 이 관찰만으로
  정해지지 않는다.

### 8. 하단 영역 / footer

- **쪽 번호**: `hp:pageNum`이 5개 중 3개(금감원 원장보고×2, 원페이지)에서
  `BOTTOM_CENTER`, 숫자 앞뒤에 `-` 기호(`-1-` 형태)로 확인됨(`REPEATED`, 과반).
  나머지 2개(광주, 한국농어촌공사)는 쪽번호 요소 자체가 없음. 쪽번호를 항상
  켤지, 조건부(옵션)로 둘지는 이 관찰만으로 정해지지 않는다 — TemplateSpec/
  Institution Design Contract의 결정 사항이다.
- **`끝.` 표기**: `SINGLE_OBSERVATION`(1/5, 금감원_원장보고_가상자산 파일).
- **보고자/연락처**: 금감원 원장보고 원문에 `"※ 1페이지 하단에 보고자 및
  연락처 등 표시"`라는 지시문이 있고, 실제로 하단에 `"○○○○○○국 국장
  ○○○(☎1111) 팀장 ☆☆☆(☎2222)"` 형태 표시가 있음(`DOCTYPE_SPECIFIC`, 원장보고류
  2/5에서 반복 — 원장보고류가 아닌 나머지 3개 파일에는 없음).
- 출처 표기 문구(`"본 자료를 인용하여 보도할 경우 출처를 표기…(http://www.fss.or.kr)"`)는
  금감원 원장보고 계열에서 관찰되나, baseline 관찰에서 제외한다 — 문구 안에
  금감원 자체 URL이 박혀 있어 레이아웃 패턴이 아니라 그 기관 고유의 텍스트
  콘텐츠이기 때문이다. "출처 표기 줄이 존재한다"는 구조 자체는 관찰로
  남기되, 문구 원문은 다른 기관에 그대로 재사용할 수 없다.

## 그룹 B — 보도자료형 baseline

근거 파일: 금감원 보도자료, 한국농어촌공사 언론보도 (표본 2개뿐 — 신뢰도가
그룹 A보다 낮은 항목은 명시)

### 1. 페이지 기본값 (2/2 실측)

| 파일 | 용지 | 좌/우 여백 | 상/하 여백 |
|---|---|---|---|
| 금감원 보도자료 | A4 세로 | 18.0mm | 15.0mm |
| 한국농어촌공사 언론보도 | A4 세로 | 20.0mm | 15.0mm |

A4 세로·상하 15mm는 2/2 일치(`COMMON`). 좌우 여백은 18mm(금감원 보도자료)와
20mm(한국농어촌공사 언론보도)로 1/2씩 갈려 그룹 B 안에서는 공통값이 없다
(`VARIABLE`). 그룹 A의 좌우 20mm와 맞출지는 baseline이 정하지 않는다 — 두
그룹을 통일된 여백으로 묶을지는 Institution Design Contract의 결정 사항이다.

### 2. Masthead — 원문 지시문 + 실측

금감원 보도자료 원문 그대로:

```
대제목 (HY헤드라인M 18p)
- 소제목 - (HY헤드라인M 13p)
1. HY헤드라인M 16p
□ 휴먼명조 16p
◦ 내용
```

- **대제목 18pt → 소제목 13pt → 섹션제목 16pt → 본문 16pt** 위계가 원문에
  명시돼 있음(신뢰도 높음, 단일 관찰이지만 기관이 직접 적은 값).
- **로고 (2026-08-13 한/글 육안 확인으로 정정)**: `hp:pic`(실제 이미지 객체)는
  2/2 전부 0개가 맞다. 그런데 금감원 보도자료를 한/글로 열어보면 masthead
  최좌측에 로고처럼 보이는 파란 원형 그래픽 + "금융감독원" 글자가 실제로
  눈에 보인다. `hp:pic`가 0인데 그래픽이 보인다는 건, 이게 삽입된 이미지가
  아니라 **특수 기호 글꼴(PUA 글자)로 그린 로고 모양**일 가능성이 높다는
  뜻이다(광주 한장보고서의 `󰏅` 기호와 같은 방식으로 추정 — PUA 글자 방식은
  해당 폰트가 없는 환경에서 깨진다는 사실 자체는 관찰로 기록한다). 관찰
  결과를 정리하면: 실제 이미지 객체(`hp:pic`)로서의 로고 사용은 0/2
  (`COMMON`), masthead 좌측에 "로고 자리"라는 레이아웃 슬롯 자체는 그룹 B
  1/2에서 관찰됨(`SINGLE_OBSERVATION`). 실제 로고를 어떤 방식(PUA 글자
  vs. `hp:pic` 이미지)으로 넣을지는 이 관찰만으로 정해지지 않는다 —
  Institution Design Contract의 결정 사항이다.
- **제목 상자**: "제목을 테두리로 감싼 별도 상자"는 2/2 전부 없음. 다만
  그룹 A와 마찬가지로 **masthead 전체가 표로 짜여 있다** — 금감원 보도자료는
  1행 3열 표(로고+"보 도 자 료"+슬로건) 아래 보도/배포일자 표, 그 아래 담당부서
  표가 이어지고, 그 아래 "대제목/소제목" 칸도 별도 표 셀 안에 있다(표 테두리로
  구획, 배경색 없음). "제목 상자 없음"이 아니라 **"장식적 배경/테두리 상자는
  없지만 표로 영역을 구획한다"**로 정정.
- **제목 정렬 (2026-08-13 한/글 육안 확인)**: masthead의 "보 도 자 료" /
  대제목 / 소제목 모두 표 셀 안에서 **중앙 정렬**로 확인됨(`COMMON`, 2/2).
  그룹 A(섹션 제목 좌측 정렬)와는 다른 관찰값이다: **그룹 B masthead
  제목류는 중앙 정렬, 본문 섹션 제목은 그룹 A와 동일하게 좌측 정렬**로
  각각 관찰됨.
- masthead 하단에 **보도시점/배포일자 + 담당부서·책임자·담당자 3단 정보표**가
  2/2 공통(`COMMON`, 이전 분석과 동일, 이번에 실측으로 재확인: 표 폭
  147~173mm, 셀 안쪽 여백 1.8mm/0.5mm, 테두리는 대부분 0.12mm 가는 실선).

### 3. 본문 작성 규칙 — 원문 지시문 (레이아웃이 아니라 "글쓰기" 규칙이지만
template_spec의 field validation/placeholder 문구 설계에 직접 쓸 수 있어 포함)

한국농어촌공사 언론보도 원문:

```
제목: 간결·압축적으로 한 줄만 - 부제(1개 권장, 최대 2개)
본문 주제문: 육하원칙 중 "누가/언제/무엇을" 필수 포함, 색·밑줄 금지
문단 구성: 두괄식, 종결어미로 완결된 문장
표기: 단어 열거 시 쉼표(가운뎃점 지양), 외국어는 "한글(외국문자)" 표기
각주: 낯선 용어는 해당 문단 바로 아래에 본문과 구분해 제시
```

→ 이건 시각 조판이 아니라 **콘텐츠 작성 규칙**이라 baseline.md 범위를 벗어나지만,
template_spec의 fields 설명/placeholder 텍스트에 그대로 반영할 가치가 있어
기록해 둔다.

### 4. 이미지 placeholder

한국농어촌공사 언론보도에 `"그림1"`, `"그림2"`라는 **텍스트 라벨**이 본문에
있음(실제 이미지 객체 아님, `SINGLE_OBSERVATION` — 그룹 B 2개 중 1개). 지금
확인된 건 "그림N"이라는 텍스트 캡션 자리뿐이고, 실제 이미지 삽입 자리의
크기/정렬/삽입 규칙은 이 샘플에 없다 — `확인 필요`. 이 관찰을 실제
template_spec에 반영할지(이미지 삽입 자리를 둘지, 어떤 형태로 둘지)는 baseline이
정하지 않는다.

### 5. 표

- 3~5개, 담당자 정보표 1개 고정(위 참고) + 본문용 표 다수.
- 표 폭 131~169mm로 그룹 A보다 편차가 큼 — 표본 2개라 뚜렷한 규칙을 뽑기엔
  이르다. `확인 필요`(표본 확대 시 재검토).

### 6. 하단 영역

- 쪽번호: 금감원 보도자료만 있음(1/2, `SINGLE_OBSERVATION`), 한국농어촌공사는
  없음. 켤지 말지는 baseline이 정하지 않는다.
- 색상: 금감원 보도자료에 `#3057B9`(파랑, 단일 관찰) 외엔 거의 무채색 —
  보도자료형은 그룹 A보다 색을 덜 쓰는 경향 (2/2 중 1개만 색 사용).

## baseline 관찰에서 제외한 것

**제외 기준은 다음 둘 뿐이다** — 반복 빈도가 낮다는 것은 제외 사유가 아니다:

1. 실제 `section*.xml`에서 참조되지 않아(styleIDRef/paraPrIDRef/charPrIDRef
   실사용 0회) 렌더링에 영향을 주지 않는 한/글 편집기 자동 등록값.
2. 파일 내부 참조용 ID 자체, 또는 실제 렌더링과 무관한 metadata·특정 기관
   고유의 문구(URL 등 재사용 불가한 리터럴 텍스트).

이번 재검증(2026-08-13 재작업)에서 이 문서 범위인 그룹 A/B **7개 파일**
(9개 원본 샘플 중 업무정보·위생점검표 2개는 애초에 이 문서 범위 밖이라 제외)
전부의 `header.xml` 등록 스타일과 `section*.xml`의 실제 `styleIDRef` 참조를
직접 교차 확인했다:

| 항목 | header.xml 등록 | section 실제 참조 (styleIDRef 사용 횟수) | 판정 |
|---|---|---|---|
| `바탕글` | 7/7 파일 | **전체 문단 수와 정확히 일치**(예: 원장보고 32/32, 언론보도 35/35) | 실제 사용됨 — 단, HWP에서 거의 모든 문단이 반드시 잇는 기본 문단 스타일 링크라 그 자체로 문서별 시각적 차이를 드러내지 않는다. 실제 시각 정보는 각 문단/run의 직접 `paraPrIDRef`/`charPrIDRef`(위 폰트/정렬/들여쓰기 절)에 있다. |
| `머리말` | 7/7 파일 | 광주 한장보고서에서만 4회(나머지 6개는 0회) — 4개 중 실제 텍스트가 있는 건 1개, 내용은 `"<'26.7.9.(목), 0000국 0000과장 000, 0000팀장 000>"` (페이지 상단 러닝 헤더) | `SINGLE_OBSERVATION` — 실제 사용됨, `UNUSED_EDITOR_DEFAULT`로 분류하지 않는다. |
| `개요 1~10`, `메모`, `미주`, `본문`, `쪽 번호`, `차례 1~3`, `차례 제목`, `캡션`, `각주` | 7/7 파일 | 7개 파일 전부에서 0회 | `UNUSED_EDITOR_DEFAULT` — baseline 관찰에서 제외. |
| 폰트 `HCI Poppy`, `한양신명조`, `한양중고딕` | 여러 파일 | 그룹 A/B 7개 파일의 실제 run에서 0회(재검증: `<hp:run charPrIDRef>`가 이 face를 가리키는 charPr을 참조한 사례 없음) | `UNUSED_EDITOR_DEFAULT` — baseline 관찰에서 제외. |

**제외하지 않고 baseline에 보존한 것** (반복 빈도가 낮아도 실제 사용이
확인됐기 때문):

- 실제 사용된 font family — `돋움체`(한국농어촌공사 언론보도에서 15회로 그
  문서 최다 사용 폰트), `바탕`, `HY견명조`, `굴림` 등. 위 3-1절 표 참고.
- 실제 font size / bold / align / 장평 / 자간 / 줄간격 — 위 3, 4절.
- 실제 color value — 위 6절.
- 실제 border/fill, cell margin, table 폭 — 위 5절.
- 단일 문서에서만 관찰된 조판 특징(광주의 `SINGLE_OBSERVATION` 불릿 기호,
  한국농어촌공사 언론보도의 "그림N" placeholder, 금감원_원장보고_가상자산의
  `끝.` 표기 등) — 반복성이 없으므로 "그룹 공통 규칙 없음"으로 판정했을
  뿐, 관찰 자체를 지우지 않았다.

출처 URL이 박힌 문구처럼 그 기관 고유의 리터럴 텍스트만 위 기준 2에 따라
제외한다(위 그룹 A 8번 참고) — 이 역시 "그 구조(출처 표기 줄)가 존재한다"는
관찰까지 지우지는 않는다.

## 관찰 빈도 요약 — 단일/저빈도 관찰 항목

아래는 그룹 전체 공통(`COMMON`)에 못 미치는 항목을 모아 놓은 것이다. 이
목록은 무엇을 template_spec에 "포함/옵션으로 넣을지"를 정하지 않는다 — 그건
Institution Design Contract·TemplateSpec 설계 단계의 결정이다. 여기서는 실제
관찰 빈도만 다시 정리한다.

1. 그룹 B "그림N" 텍스트 라벨 placeholder — `SINGLE_OBSERVATION`(2개 중 1개,
   한국농어촌공사 언론보도). 실제 이미지 객체 아님.
2. 그룹 A 로마숫자 다단 구성(Ⅰ./Ⅱ. + 가/나) — `SINGLE_OBSERVATION`(5개 중
   1개, 금감원 원페이지).
3. `끝.` 종결 표기 — `SINGLE_OBSERVATION`(5개 중 1개, 금감원_원장보고_가상자산).
